# سرّ الدار الموصلية

لعبة ألغاز «هروب من غرفة» داخل بيت موصلي قديم، تعمل في المتصفح مباشرة.

## التشغيل
افتح ملف `index.html` بالضغط عليه مرتين — لا يحتاج أي تنصيب أو خادم.

## طريقة اللعب
- اضغط على الأشياء في الغرفة لتفحصها أو تلتقطها.
- الأغراض تظهر في الشريط السفلي: اضغط على غرض لاختياره ثم اضغط على شيء في الغرفة لاستخدامه عليه، أو اسحبه وأفلته مباشرة.
- اضغط على الغرض مرتين (أو زر «افحص») لقراءته أو فحصه.
- زر «تلميح»: ثلاثة تلميحات متدرّجة لكل مرحلة (تؤثر على النجوم).
- `Esc` أو الزر الأيمن يلغي اختيار الغرض أو يغلق النافذة المقرّبة.
- التقدّم يُحفظ تلقائياً، وتكمل من زر «أكمل».

## أمر التجربة المخفي
اضغط **N** أثناء اللعب للانتقال مباشرة للغرفة التالية (تُسجَّل الغرفة «تخطٍّ»).

## الغرف المتوفرة حالياً (الجزء الأول)
1. **الدهليز** — قفل أرقام مخفية في تفاصيل الغرفة.
2. **قاعة المرايا** — تدوير المرايا لإيصال شعاع الضوء إلى البلّورة.
3. **المكتبة** — ترتيب الكتب حسب ألوان الزجاج المعشّق وأطوالها.

قادماً: غرفة القاشاني (بلاطات منزلقة)، غرفة المقام (ذاكرة نغمات)، والسرداب.

## التقنية
HTML + CSS + JavaScript فقط. الرسوم كلها SVG، والأصوات مولّدة بـ Web Audio API.
