# طريق الألف ميل

لعبة متصفح كاملة بملف واحد (`index.html`): HTML + CSS + JavaScript باستخدام Canvas، بدون أي مكتبات أو صور خارجية. كل الرسوم (Pixel Art) والأصوات (Web Audio) مولّدة بالكود.

إنت **مصطفى**، خريج علوم حاسبات من الموصل، عندك ٣٠ يوم و١٥٠ ألف دينار حتى تلگى طريقك.

## التشغيل

افتح `index.html` بأي متصفح حديث (كروم، فايرفوكس، سفاري، أو متصفح الموبايل). ما يحتاج سيرفر ولا إنترنت.

## التحكم

| الحركة | الأسهم أو `W A S D` (وبالموبايل الجويستك) |
|---|---|
| التفاعل / الحچي / الدخول | `E` أو `Space` أو زر «تفاعل» |
| خريطة العراق | `M` |
| الموبايل | `P` |
| القائمة | `Esc` |
| الاختيارات بالحوار | الأرقام `1` `2` `3` أو الأسهم |

## المحتوى

- **خمس فصول**: الموصل، الواسطة، السفر، الانهيار، الفرصة.
- **خمس مدن بعالم مفتوح**: الموصل (الأكبر)، بغداد، أربيل، البصرة، كركوك. فيها سيارات تمشي، مارة، ودورة ليل ونهار.
- **أنظمة**: الفلوس، الأمل، الطاقة، الأيام، الموبايل، السيرة الذاتية، العلاقات، والسمعة.
- **ألعاب مصغرة**: تصليح موبايلات، نادل، شيل صناديق، وتوزيع طرود بالعالم المفتوح، ومقابلات عمل بمؤقت.
- **خمس نهايات**: الخطوة الأولى، ورشة أبوي، الطريق الطويل، الغربة، انطفى الضوء.
- **حفظ تلقائي** بالمتصفح (localStorage).

## تعديل اللعبة

الكود مقسّم بعناوين واضحة داخل `index.html`. دوّر على العناوين هاي:

| القسم | شنو بي |
|---|---|
| `[١] الإعدادات` | `CFG` (فلوس البداية، سرعة الوقت...) و`HOURS` (ساعات الدوام) |
| `[٢] الصوت` | المؤثرات والموسيقى (مقام بيات) |
| `[٣] حالة اللعبة` | `newState()`، الحفظ، ودوال تغيير الإحصائيات |
| `[٤]` و`[٥] الرسم` | رسم الشخصيات، الوجوه، البنايات، السيارات |
| `[٦] الخريطة` | `CITY_DEFS`: تصميم كل مدينة (شوارع، بنايات، نقاط تفاعل) |
| `[٧] الداخليات` | `INTERIORS`: جوه كل بناية (أثاث، شخصيات) |
| `[٨] الشخصيات` | `LOOK` و`NPC` وجمل المارة وسايق الكيا |
| `[٩] القصة` | `TALK` (حوارات الشخصيات)، `ACT` (التفاعلات)، والفصول |
| `[١٠] الأنظمة` | نهاية اليوم، الشغلات، المقابلات (`IV`)، السفر، الأهداف، النهايات |
| `[١١] الواجهة` | صندوق الحوار، الموبايل، خريطة العراق، الألعاب المصغرة |
| `[١٢] العالم` | الحركة، التصادم، الإضاءة، الإدخال، الحلقة الرئيسية |
