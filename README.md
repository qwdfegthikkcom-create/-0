# مسيرة نجم ⚽

لعبة متصفح عربية: اصنع لاعباً عمره 16 سنة وعِش مسيرته من أكاديمية الشباب حتى المجد.

> الحالة: **المرحلة 1 مكتملة** (نسخة أولى قابلة للعب). راجع `PLAN.md` لما تبقى، و`SPEC.md` للمواصفات الكاملة.

## التشغيل

- افتح `index.html` مباشرة في المتصفح (كروم أو إيدج أو فايرفوكس أو سفاري) — لا تحتاج أي تثبيت.
- أو ارفع المجلد كما هو على أي استضافة ثابتة (مثل Netlify).
- الخطوط من Google Fonts، وإن لم يتوفر الإنترنت تعمل اللعبة بخطوط الجهاز.

## كيف تلعب (المرحلة 1)

1. **مسيرة جديدة**: الاسم، الجنسية، المركز، الطول والوزن، الشكل، والصعوبة.
2. كل أسبوع: **خطة الأسبوع** — تدريب فردي (لعبة التسديد المصغّرة أو تدريب تلقائي)، راحة، تحليل فيديو، أو وقت مع العائلة.
3. **المباراة الكاملة** (الوضع الافتراضي): تلعب المباراة كلها وتتحكم بلاعبك فقط، مثل «مهنة اللاعب» في بيس وفيفا، في ملعب ثلاثي الأبعاد.
   - **الهاتف**: اسحب على يسار الشاشة للحركة (عصا تحكم)، والأزرار يميناً: تمرير، بينية، عالية/عرضية، **تسديد** (اضغط مطولاً للقوة ووجّه بالعصا)، ركض. بدون الكرة: اطلب الكرة، افتكاك، انزلاق، ضغط.
   - **الكمبيوتر**: الأسهم للحركة، Shift ركض، S تمرير، W بينية، A عالية، D أو المسافة تسديد، C الكاميرا، Esc إيقاف.
   - ثلاث كاميرات: تلفزيونية، خلف اللاعب، واسعة. يُفضَّل إمالة الهاتف أفقياً.
   - الحكم كامل: أخطاء وبطاقات وجزاء وركنيات وتسلل. يمكنك «محاكاة البقية» في أي لحظة، والمدرب قد يستبدلك إذا تعبت.
   - المدة من الإعدادات أو قبل المباراة: 8، 12، 16، 20 دقيقة.
4. **وضع اللحظات** (من الإعدادات): التعليق يسير دقيقة بدقيقة، وعند اللحظة الحاسمة تتوقف وتتحكم أنت:
   - اسحب من الكرة **للخلف** ثم أفلت = تسديدة أو تمريرة في المساحة (كلما سحبت أكثر زادت القوة).
   - اضغط على **زميل** = تمريرة أرضية له.
   - زر «كرة عالية» للكرات الساقطة، وزر «لعب تلقائي» إذا أردت أن يقرر الذكاء الاصطناعي.
   - على الكمبيوتر: المسافة = تسديد سريع، 1–4 = تمرير لزميل، L = كرة عالية، A = لعب تلقائي.
5. **إنهاء الأسبوع**: تُحاكى كل الدوريات، ترى تطورك (+1)، ويُحفظ تقدمك تلقائياً.

## الاختبار

```
node tests/sim-check.js          # 20 موسماً + اللحظات + المباراة الكاملة + مسيرة تلقائية + الحفظ
node tests/sim-check.js --quick  # 5 مواسم فقط
```

يطبع كل مقياس واقعية مع PASS/FAIL (متوسط الأهداف، نسب الفوز والتعادل، الهدافون، التقييمات، البطاقات، منحنى التطور حسب العمر، نسب تحويل اللحظات...).

## تعديل الواقعية

كل أرقام التوازن في ملف واحد: **`js/data/balance.js`** وكل رقم معه تعليق عربي. أمثلة:

| تريد... | عدّل |
|---|---|
| أهدافاً أكثر أو أقل | `match.chancesBase` |
| فرقاً أوسع بين القوي والضعيف | `match.strengthK` |
| أفضلية أكبر لصاحب الأرض | `match.homeMult` / `match.awayMult` |
| هدافين بأرقام أعلى | `match.shooterW` (وزن المهاجم) |
| تطوراً أسرع أو أبطأ | `growth.ageTable` |
| حارساً أقوى في اللحظات | `moments.gkReach` و`moments.gkReact` |
| لحظات أكثر للمهاجم | `moments.count.ST` |
| أهداف أكثر/أقل في المباراة الكاملة | `full.goalK` و`full.shootWill` |
| حارس أقوى في المباراة الكاملة | `full.gkReachAdd` و`full.gkDiveMult` |
| أخطاء وبطاقات أكثر | `full.foulBase` و`full.yellowOfFoul` |

بعد أي تعديل شغّل `node tests/sim-check.js` للتأكد أن الأرقام ما زالت واقعية.

## البنية

- `js/core` الأساسيات (مولّد الأرقام، التقويم، الحفظ)
- `js/data` البيانات (التوازن، الدول، الأسماء، الدوريات، النصوص العربية)
- `js/sim` منطق اللعبة بدون واجهة (يُختبر في Node)
- `js/game` اللحظات والألعاب المصغّرة والمباراة الكاملة ثلاثية الأبعاد على canvas
- `js/ui` الشاشات
