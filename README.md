# طريق الألف ميل

لعبة متصفح كاملة بملف واحد: `index.html` (HTML + CSS + JavaScript وCanvas). ما بيها أي مكتبات أو صور خارجية، وكل الرسوم والأصوات مولّدة بالكود.

إنت مصطفى، خريج علوم حاسبات من الموصل، وبجيبك 150,000 دينار وعندك 30 يوم حتى تلگى خطوتك الأولى.

## التشغيل
افتح `index.html` بأي متصفح حديث. ما تحتاج سيرفر ولا إنترنت.

## التحكم
| الفعل | الكيبورد | الموبايل |
|---|---|---|
| المشي | الأسهم أو WASD | الجويستك |
| الحچي / التفاعل / الدخول | E أو Space | زر "تفاعل" |
| خريطة العراق والسفر | M | زر "خريطة" |
| الموبايل (رسائل، وظائف، أسماء، سيرة، حقيبة) | P | زر "موبايل" |
| اختيار بالحوار | 1 / 2 / 3 | اضغط على الخيار |

## المحتوى
- **خمس فصول:** الموصل، الواسطة، السفر، الانهيار، الفرصة.
- **خمس نهايات:** الخطوة الأولى، ورشة أبوي، الطريق الطويل، الغربة، انطفى الضوء.
- **خمس مدن:** الموصل (مدينة كاملة، وبيها 7 أماكن داخلية)، بغداد، أربيل، البصرة، كركوك.
- **الأنظمة:** الفلوس، الأمل، الطاقة، الوقت (ليل ونهار ودوام الشركات)، الموبايل، السيرة الذاتية، العلاقات، السمعة، والحفظ التلقائي.
- **ألعاب مصغّرة:** لحيم بالورشة، نادل بالمطعم، توزيع إعلانات، تحميل بالميناء، ومقابلات بـ 5 أسئلة (صادق / متكبر / خجول).

## تنظيم الكود
الكود مقسّم بتعليقات مرقّمة داخل `index.html`:
1. الأدوات العامة
2. الأصوات (Web Audio)
3. حالة اللعبة والحفظ
4. الشخصيات (الأشكال، رسم الوجوه، رسم الشخصيات بالعالم)
5. الخرائط والمدن والأماكن الداخلية
6. الرسم المسبق للخرائط
7. الواجهة (الحوار، النوافذ، الـHUD، الموبايل، خريطة العراق)
8. الأنظمة (الوقت، النوم، السفر، الشغل المؤقت، المقابلات)
9. القصة (الحوارات `TALK`، الأشياء القابلة للتفاعل `ACTS`، أحداث الفصول `EV`)
10. النهايات
11. المحرك (الحركة، الاصطدام، المارة، السيارات، الإضاءة)
12. التحكم
13. الشاشة الرئيسية والتشغيل
